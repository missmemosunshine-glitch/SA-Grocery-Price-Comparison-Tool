# SA Grocery Price Comparison Tool

## Overview

SA Grocery Price Comparison Tool is an AI-powered app designed to help South African shoppers compare grocery prices across major supermarkets.

The app helps users find the best deals, track specials, and save money on everyday grocery items.

## Supermarkets Included

* Spar
* Checkers
* Pick n Pay
* Game
* Makro

## Features

* Compare grocery prices between stores
* Track specials and discounts
* Display special start and expiry dates
* Calculate customer savings
* Compare online ordering specials and walk-in specials
* Recommend the best shopping times
* Simple and user-friendly interface

## Grocery Products Compared

* Bread
* Milk
* Sugar
* Coffee
* Cheese

## Technologies Used

* Amazon PartyRock
* Generative AI
* Prompt Engineering

## Purpose

This project was created to help customers make smarter shopping decisions and reduce grocery costs using AI-powered comparisons and insights.
